# OneKore UI component library

OneKore UI is a premium, expressive UI component library built on top of **Compose Multiplatform** and **Material 3**. It offers developers pre-styled, responsive components designed for dynamic branding, animations, and beautiful data visualization.

## Visual Foundations
- **Material 3 Expressive Tones**: Vibrant accent colors paired with carefully structured container cards.
- **Micro-Animations**: Smooth visual transitions built using Compose's physics-based animation API.
- **Dark Mode First**: First-class support for both high-contrast light modes and deep, premium dark themes.

## Highlighted Components
- **Wavy Divider**: A customizable, animated sine-wave line to separate content sections.
- **Bento Card**: Rounded bento containers with stateful hover animations.
- **Glass Dock**: A blurred, transparent floating navigation panel.
