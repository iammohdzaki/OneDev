# DevTerm Developer Portfolio

This is a personal developer portfolio built with **Kotlin Multiplatform (KMP)** targeting **WebAssembly (WASM)**.

## Visual Design
- Paired HSL dynamic dark styling with modern **Material 3 Expressive** shapes.
- Incorporates custom animated widgets like the sine-wave divider.
- Full support for responsive grids (mobile stack, tablet columns, desktop left navigation rail).

## Performance
- Compiled to WebAssembly (WASM) for near-native UI performance directly inside web browsers.
- Powered by Skiko rendering engine to run identical graphics code across multiple platforms.
