# JsonBox Toolkit

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)
![Next.js](https://img.shields.io/badge/Next.js-14+-black?style=for-the-badge&logo=next.js)

**[🔥 Live Demo - jsonbox-toolkit.vercel.app](https://jsonbox-toolkit.vercel.app/)**

JsonBox Toolkit is a completely client-side, fast, privacy-focused web application for manipulating, formatting, and interpreting JSON data.

Built with **Next.js**, **React**, and **TypeScript**, it provides lightning-fast utility tools in a sleek IDE-like environment without sending your sensitive JSON data to any backend server.

---

## ✨ Features

- **JSON Formatter**: Prettify, validate, and structure your unformatted JSON payloads.
- **JSON Minifier**: Compress standard formatted JSON into a single line to reduce size.
- **JSON Diff Viewer**: Compare two different JSON files side-by-side to visually see the differences.
- **JSON Stringify / Parse**: Easily escape JSON strings for variables, or unescape strings back into standard JSON.
- **Privacy First**: Everything runs entirely locally in your browser! Zero data is sent to external servers.
- **Modern UI**: Polished glassmorphic dark and light themes with premium interactions.
- **PWA / App-Like**: Collapsible left sidebar, responsive panes, and IDE-like "Monaco Editor" experiences.

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **UI & Components**: React + custom CSS Variables (Glassmorphism & Theme Toggle)
- **Editor**: [@monaco-editor/react](https://github.com/suren-atoyan/monaco-react) for advanced code manipulation.
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com)
